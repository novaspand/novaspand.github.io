06 — What to steal from each reference
Pentagram
Work-first homepage. Type as navigation. Almost no decoration.
Steal: generous whitespace + type hierarchy
Wolff Olins
Yellow accent on near-white. Serif + sans pairing. Bold confidence in copy.
Steal: accent colour restraint + voice
Architecture studios
Slow scroll. Off-white surfaces. Work speaks, studio doesn't shout.
Steal: pacing, warmth, quiet confidence
DeSo / editorial web
Oversized H1 bleeding near the edge. Asymmetric layout earns its place.
Steal: H1 scale + italic accent treatment
07 — What Novaspand is not
Gradient text or glassmorphism — both scream "SaaS template 2022"
Card grid for features — prose lists are more confident
Animated counter stats — you're early, don't fake the numbers
Hero illustration or 3D object — type IS the visual
Multiple accent colours — terracotta only, always
"Passionate team of experts" — the copy brief already solved this
