/ 002 · philosophy

The name says it.

Novaspand comes from two roots: Nava (new, fresh, innovative) and Spanda (the creative pulse, the vibration behind all creation). Together: the new creative pulse.

We didn't pick the name because it sounds good. We picked it because it describes how we think. Every product we ship starts with a problem that bothered someone. Every system we build gets better the more it's used. We move fast. We build to last.

We are a studio, not an agency. We have opinions. We push back. We ship.

"The name is the cheapest part. Now we ship."
